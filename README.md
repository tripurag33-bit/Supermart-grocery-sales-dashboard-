# Supermart-grocery-sales-dashboard
Supermart Grocery Sales Dashboard is a data analytics project focused on analyzing sales, profit, product.This interactive dashboard shows Total Sales, Total Profit, Total Orders, and Average Discount in one place. Users can filter data by Category (Dairy, Bakery, Beverages, Vegetables, Snacks) and by City (Shillong, Guwahati, Agartala, Aizawl).
# Supermart Grocery Sales Dashboard

Supermart Grocery Sales Dashboard | Excel Data Analytics Project

Project Description

This project focuses on analyzing Supermart Grocery Sales data using Microsoft Excel to develop an interactive business dashboard.

The objective is to transform raw sales data into meaningful insights that help understand business performance, sales trends, profitability, product performance, discount patterns, and regional contributions.

Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Orders
- Average Discount
- Profit Margin

Key Analysis

- Overall sales and profit performance
- Category-wise and sub-category-wise sales analysis
- Yearly and monthly sales trends
- Regional sales and profit comparison
- Discount and profitability analysis
- City-level geographic performance

Tools & Skills

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Interactive Slicers
- Dashboard Design
- Data Analysis and Visualization

Project Outcome

The project converts raw grocery sales data into an easy-to-understand visual dashboard. It helps identify top-performing categories, profitable regions, sales trends, and opportunities for better business decisions.

Project Type: Data Analytics | Excel Dashboard
Dataset: Supermart Grocery Sales
Records: 9,994
Period: 2015–2018
